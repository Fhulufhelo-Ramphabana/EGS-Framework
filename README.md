# EGS-Framework
Code and supporting materials for the Explainability–Governance Score (EGS) Framework for multidimensional machine learning model selection.

## Repository structure and paths

The analysis workflow is organised around the repository folder structure. Users should clone or download the repository while preserving the relative directory structure.

Where local absolute paths are required, these should be updated to the user's own working directory. Output directories may also be changed as needed, provided the corresponding paths in the notebooks are updated consistently.
